## 📄 Project Description

This repository provides a reproducible and portable development environment using [Jetify Devbox](https://www.jetify.com/devbox). With a single command, you can initialize pre-configured environments tailored for multiple use cases:

- ✅ **Terraform Provider Development** with Go, golangci-lint, and goreleaser
- ✅ **Terraform, Terragrunt & Ansible Projects** with required CLI tools and linters
- ✅ **Function App Development** using Python, pip, Docker, Docker Compose, Colima, and Azure Functions Core Tools

The setup ensures fast onboarding and consistent tooling across macOS, Linux, and Windows (via WSL).
